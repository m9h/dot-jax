Morgan is a neuroimaging researcher building a JAX ecosystem for computational neuroscience:
- **dot-jax** — Diffuse Optical Tomography / fNIRS
- **neurojax** — whole-brain dynamics (Balloon-Windkessel, neural mass models)
- **vpjax** — vascular physiology
- **sbi4dwi** — simulation-based inference for diffusion MRI

Works with the WAND dataset (Cardiff CUBRIC, 300 mT/m Connectom), Kernel Flow 2, OpenNeuro datasets. Collaborates with John Griffiths (CAMH/UofT, EEG-ExPy Kernel Flow support).

Preparing for Global NeuroHack (April 10-12, 2026) with a demo showing fNIRS-guided TMS targeting for the SAINT depression treatment protocol.

Interested in connecting structural connectivity (TRIBE model) → predicted fNIRS activation → real-time DOT reconstruction → TMS target identification.
